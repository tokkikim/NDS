기존 커리큘럼의 레슨마다 "매일 할 일(daily)"을 채워 주세요. 이 파일은 `npm run curriculum -- --daily`가 값을 채워 Claude CLI에 넘깁니다.

## 대상

- 카테고리: {{topicName}} — {{topicDescription}}
- 파일: `{{file}}` (이 파일만 수정하세요)
- 운영자 프로필: `research/profile.md` (먼저 읽고 수준·나이·직장 병행 같은 현실 조건을 반영하세요)

## 운영 방식

- 글은 카테고리 {{cadence}}개를 하루씩 돌아가며 쓰지만, **공부·훈련은 모든 카테고리를 매일** 합니다.
- 그래서 레슨 1개 = {{cadence}}일짜리 실천 블록입니다. daily[0]이 1일차, daily[{{last}}]가 마지막 날이며, **마지막 날이 그 레슨 글을 쓰는 날**입니다.
- 운영자는 이 카테고리 말고도 다른 카테고리 {{others}}개의 할 일을 같은 날 함께 합니다. 하루 분량은 현실적으로 잡으세요.

## 작성 규칙

1. 레슨마다 `"daily"` 배열을 **정확히 {{cadence}}개** 넣으세요. 이미 daily가 있는 레슨은 그대로 두세요.
2. 각 항목은 그날 할 구체적인 행동 한 줄 + 기록할 것. 레슨의 task(블록 전체 목표)를 {{cadence}}일에 나눠 실행하는 형태로 쓰세요.
3. 마지막 날은 가벼운 실천 + "블록 기록 정리(글 재료)"를 포함하세요.
4. 운동 카테고리는 강도 조절이 핵심입니다: 고강도(인터벌·템포·롱런) 다음 날은 이지런·휴식·근력 등으로 회복을 넣고, 주간 흐름이 무리하지 않게 하세요.
   날짜가 고정된 레슨(대회 당일 등)과 그 전후 레슨은 대회 일정에 맞게 쓰세요 (예: 대회 전날은 휴식·준비).
5. 공부 카테고리는 하루 20~40분 안에 끝낼 분량으로, "읽기 → 해보기 → 기록" 흐름이 되게 하세요.
6. 다른 필드(id, title, task, keywords, date, event, stages 구조)는 한 글자도 바꾸지 마세요. daily만 추가합니다.

예시:
```json
"daily": ["이지런 40분(존2) + 심박·페이스 기록", "휴식 또는 코어 근력 20분, 다리 상태 메모", "템포런 6km(목표 페이스) 후 블록 기록 정리"]
```

파일 전체를 올바른 JSON으로 다시 저장하세요. 마지막 답변은 "daily를 채운 레슨 수" 한 줄로만 쓰세요.

## 파일 쓰는 방법

- 파일이 길면 한 번에 쓰지 말고 나눠 쓰세요: 먼저 Write로 전체 뼈대(목표·단계, 레슨은 첫 단계만)를 쓰고,
  나머지 단계는 Edit으로 하나씩 추가하세요. 한 번의 도구 호출에 레슨 10개 이하가 적당합니다.
- 파일은 Write/Edit 도구로만 쓰세요. 셸 명령(cat, echo 등)으로 파일을 쓰는 것은 허용되지 않아 실패합니다.
- 도구가 실패하면 같은 방법을 반복하지 말고 더 작게 나눠서 다시 시도하세요.
