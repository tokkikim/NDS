## 블로그 운영 방식 (분석 전제)

- 개인이 운영하는 "공부 기록" 블로그. 매일 1편, 여러 주제를 돌아가며 씀.
- 모든 글에 운영자의 "직접 해보기" 경험이 들어감. AI 대량 생성 글은 쓰지 않음.
- 수익원: 구글 애드센스, 쿠팡파트너스 등 제휴, 장기적으로 전자책·템플릿 판매 가능.
- 유입: 네이버·구글 검색. 2026년 현재 AI 검색 요약으로 단순 정보성 검색 클릭이 크게 줄어든 상황.

## 조사 방법

1. **키워드 수집**: 이 주제의 대표 검색어 5~10개를 정하고 네이버 데이터를 조회하세요.
   - `npm run -s naver -- keywords 키워드1 키워드2 ...` → 연관 키워드, 월간 검색량, 광고 경쟁도
   - `npm run -s naver -- trend 키워드1 키워드2 ...` → 최근 12개월 추세 (최대 5개)
   - `npm run -s naver -- bid 키워드1 키워드2 ...` → 광고 입찰가 (수익성 참고)
   - 결과가 `"available": false`이면 API 키가 없는 것입니다. 이때는 dataMode를 "estimate"로 하고,
     웹 검색으로 찾은 근거로 추정하되 리포트에 "추정"이라고 분명히 표시하세요. 검색량 숫자를 지어내지 마세요 (null로 두세요).
2. **경쟁 조사**: WebSearch로 대표 키워드 3~5개를 검색해서 상위 결과가 누구인지 보세요.
   공식기관·대형 언론·대형 블로거가 장악했는지, 개인 블로그나 오래된 글이 끼어 있는지가 핵심입니다.
3. **수요의 실체**: 네이버 지식iN, 커뮤니티, 유튜브 댓글 등에서 입문자가 실제로 묻는 질문을 찾으세요.
4. **수익화**: 이 주제로 팔 수 있는 제휴 상품·서비스, 광고 단가 수준, 디지털 상품 가능성을 조사하세요.
5. **AI 대체 위험**: 대표 질문들이 AI 한 줄 답변으로 해결되는지, 직접 경험과 최신 정보가 필요한지 판단하세요.
