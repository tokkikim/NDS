## 작업 순서

1. **키워드 확장**: 카테고리의 핵심 키워드로 네이버 데이터를 조회하세요.
   - `npm run -s naver -- keywords 키워드1 키워드2 ...` (연관 키워드, 월간 검색량, 경쟁도)
   - `npm run -s naver -- trend 키워드1 ...` (필요하면 추세)
   - `"available": false`면 WebSearch(연관 검색어, 지식iN 질문 등)로 대신하고, 검색량은 "추정"으로 표시하세요. 숫자를 지어내지 마세요.
2. **묶기**: 키워드를 검색 의도(개념 / 방법 / 비교 / 후기·경험)별로 묶고, 묶음마다 "핵심 글" 1개와 "하위 글" 여러 개로 구성하세요.
   핵심 글은 넓은 키워드를 총정리하는 글, 하위 글은 구체적인 질문 하나를 해결하는 글입니다.
3. **거르기**: 운영자가 직접 해볼 수 없는 소재, AI 한 줄 답변으로 끝나는 소재, 법적 책임이 큰 소재(특정 종목 추천 등)는 빼세요.
4. **정렬**: 입문자가 따라가기 좋은 순서를 기본으로, 같은 수준이면 (검색량 높음 × 경쟁 낮음) 순으로 앞에 두세요.
   하위 글보다 핵심 글이 먼저 오게 하세요.
5. 계획 파일의 `## 대기` 목록 **맨 아래에** {{count}}개를 추가하세요. 기존 항목과 `## 완료`는 건드리지 마세요.

```markdown
- [ ] 검색에 걸리는 구체적인 글 제목 후보
  - 키워드: 대표 키워드 (월 12,300 · 경쟁 높음), 보조 키워드 (월 800 · 경쟁 낮음)

  - 수익: 연결할 수 있는 제휴 상품이나 광고 단가 메모 (없으면 생략)
```
